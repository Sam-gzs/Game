# 交互判定表

依据当前代码逐条整理（`GridTile.cs` / `BoxProjectile.cs` / `PlayerController.cs` / `GateSystem.cs`）。
"动量" 指球的 `speedLevel`（蓄力 1~3，可被反射/下落累加到 5）。

## 1. 球 × 粘液块

| # | 情形 | 条件 | 结果 | 位置 |
|---|---|---|---|---|
| 1.1 | 球撞上**自由**粘液块（未被携带、未锚定、没被落块拖） | 动量 1–2 | 粘液块被推到球**前方**，球跟进它原来的格 | `OnBlocked` |
| 1.2 | 同上 | 动量 ≥3 | 交换：球进入粘液块格，粘液块退到球**后方** | `OnBlocked` |
| 1.3 | 球撞上**已锚定**或**正被落块拖**的粘液块 | 动量 <4 | 球停住、动量清零、`stuck` | `OnBlocked` |
| 1.4 | 同上 | 动量 ≥4 | **球穿过**，粘液块不动 | `OnBlocked` |
| 1.5 | 球走完一格后，**上下左右**邻接已锚定且未被携带的粘液块 | 动量 <4 | 球被粘住、动量清零 | `CheckStickyContact` |
| 1.6 | 球与已锚定粘液块**斜角**相邻 | — | **不触发吸附**（只查 4 邻接） | `CheckStickyContact` |
| 1.7 | 球携带粘液块移动 | 目标格距离 ≤ 1 | 粘液块跟过去 | `MoveToCell` |
| 1.8 | 同上 | 距离 > 1（球转向） | 粘液块**这一帧不动**，携带关系保留 | `MoveToCell` |
| 1.9 | 球被回收 / 销毁 | — | 粘液块松手，留在原地 | `DetachFromBall` |
| 1.10 | 瞄准线预览 | 自由粘液块 | 预览里当可穿过（近似，见备注） | `BuildPreview` |

## 2. 粘液块 × 地形

| # | 情形 | 结果 |
|---|---|---|
| 2.1 | 下方是 实体 / 石头 / 木块 / 土块 / 关闸 | 有支撑 |
| 2.2 | 下方是 按钮 / 压力板 / 球压开关 / 果冻 / 触发块 / 开闸 | **无支撑**（当空格） |
| 2.3 | 下方有球 | 有支撑 |
| 2.4 | 上下左右邻接 实体 / 石头 / 木块 / 土块 | 视为"被粘住"：球推不动它，只有落块能改变它 |
| 2.5 | 上下左右邻接 开关 / 果冻 / 镜面 / 折射 / 闸门 / 球 | **不算**粘住 |
| 2.6 | 被球携带时进入某格，该格 4 邻接普通砖 | 立刻粘住、停止跟随 |
| 2.7 | 同上，但该格是**开关格** | **不粘**，继续跟着球走 |
| 2.8 | 自由粘液块（哪都不挨） | 浮空，不自己下落 |
| 2.9 | 被落块拖，下方没块 | 跟着落块逐格下落 |
| 2.10 | 被落块拖，下方有块 | 原地不动，落块独自落 |

## 3. 开关（BallSwitch / Switch / Plate）

| # | 情形 | 结果 |
|---|---|---|
| 3.1 | 球在球压开关格内 | ON；球离开/被回收立即 OFF |
| 3.2 | 落块 / 粘液块在格内 | 无影响（不触发） |
| 3.3 | 玩家在格内 / 撞上去 | 无影响（玩家不能操作开关） |
| 3.4 | 开关对球、落块、粘液块的移动 | **完全无影响**：不阻挡、不支撑、不锚定 |
| 3.5 | 状态结算时机 | `LateUpdate`，所有运动结算完之后 |
| 3.6 | 开关驱动闸门/镜面 | 通道奇偶 → 开合（同一 `LateUpdate` 内） |

## 4. 备注 / 已知近似

- 1.6 斜角不吸附：`CheckStickyContact` 只查上下左右四格。
- 1.10 预览线不模拟"粘液块被推走/被携带/被粘住"，只模拟"已锚定粘液块会把球停下"。
- 2.7 开关格不粘：这是为了"开关不参与运动"而加的例外，开关以外的格子仍按 2.6 处理。
