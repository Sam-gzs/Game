## 1. 美术与音效缺口清单

### 1.1 美术（按优先级）

**P0 — 不做会被一眼看出"未完成"**

1. **方块贴图集**（现在全是纯色方块，这是最伤画面的一环）
   需要 16×16 或 32×32 图元：墙/砖(Solid)、硬石(Stone，3 级)、木头(Wood，2 级)、土(Dirt，1 级)、弹块(Bounce)、裂块(Falling)、闸门(Gate，2 格高)、开关两态(SwitchOn/Off)、压力板两态(Plate)、反射镜两态(Mirror)、折射镜两态(RefractDown/Up)、黏块(Sticky)、果冻(Jelly)、滑面(Slider)、加球道具(Pickup)、门(Door，1×2)、出生点标记。**共约 19 个图元**。
   建议做**图集 + 9-slice 边角**，让 1 格和 3 格宽的墙都能用同一套素材。
2. **球的动量外观**：现在靠 `SpeedColor()` 从红→橙→黄→白→青变色表示 1–5 级动量。颜色语义对新手不直观，建议改成 **3 档大小/表情**（小猫球：眯眼→睁眼→炸毛），颜色仅作辅助。
3. **角色缺动作**：现有只有 idle + 6 帧走路（`StickmanRig` 里跳跃是**借用走路帧**，代码注释也承认"push 动画未实现"）。
   缺：起跳、下落、蓄力（握球）、投掷、被方块挤、通关开心。**最少补 4 个动作 × 2 帧**。
4. **UI 素材与像素字体**：现在全部由 `UIFactory` 代码生成纯色矩形，字体是 `LegacyRuntime.ttf`（Arial 系），中文靠系统字体 fallback，和像素风完全不搭。
   需要：9-slice 面板、按钮三态、图标（音量/暂停/重开/右箭头）、**中文像素字体**（Fusion Pixel 12px 简中 / Zpix，均免费可商用）。
5. **标题 Logo**：`MainMenu` 现在是纯文字 "STICKMAN BOUNCE"，无 logo、无标题演出。

**P1 — 明显提升完成度**

6. **背景视差**：目前相机清屏色 `(0.045,0.052,0.075)` 就是全部背景，关卡内是"黑底 + 方块"。至少 2 层视差（远景剪影 + 近景装饰），3 个主题轮换（工厂/森林/冰洞）。

## 4. 玩法扩展：3 条与现有实现不同的"碰撞"机制

现有已实现：动量分级投球（1–3，+落体/+镜面，-折射/-果冻/-破块）、折射镜 90°、反射镜反弹、弹块、黏块携带、果冻减速、滑面、三级可破坏、落块、开关/压力板/闸门/球压开关、加球道具。

以下三条都**复用现有架构**（`BoxProjectile.OnBlocked` / `GridTile.OnSignal` / `PlayerController.Throw`），不需要重写核心。

### 方案 A：动量传递（Momentum Exchange）——"撞球连锁"

**机制**：新增"弹性撞球"方块。球撞上它时**不停下，而是把动量传过去**：撞球按收到的动量向同方向平移 N 格（N = 球当前的 speedLevel），球自身降到 1 级并停住。撞球撞到别的东西时同样继续传递。

**与现有实现的区别**：现在撞到静止的球只会"推 1 格"（`OnBlocked` 里 `other.Push(dir)`，固定 1 格）。A 方案把它升级成**按动量决定推进距离的连锁反应**。

**关卡草图（可直接替换 Level8 的压力板单屏关）**
```
#####################
#...................#
#.........O.........#      O = 压力板（2 号通道）
#...................#
#....S..............#      S = 撞球
#..P.......####.....#
#####################
玩法：站在左侧，向 3 级蓄力打向右边的撞球 → 撞球滑 3 格压住压力板 → 闸门打开。
若只蓄 2 级，撞球停在压力板前 1 格，需要重来（R 或 E 收球）。
```
**成本**：程序 ½ 天（`Push` 加距离参数 + 动量清零逻辑 + 预览线同步）。

### 方案 B：后坐力（Recoil）——"用扔球来移动"

**机制**：扔出球的瞬间给玩家一个**反向冲量**，大小与蓄力等级成正比。配合"没有地面 / 冰面"区，玩家必须**朝反方向扔球**才能飞过缺口。

**与现有实现的区别**：当前 `Throw()` 对玩家没有任何反作用，且规则是"空中不能扔球"（`if (!Grounded) return`）。B 方案把这两点反过来：**空中可以扔一次**，且扔球就是位移手段。这是把"碰撞"从"球撞环境"扩展到"球撞人"。

**关卡草图**
```
############################
#..........................#
#..........................#
#.P...................E....#
#..........................#
#####.........#####........#     中间 5 格无地面
############################
玩法：跑到缺口边缘起跳，在空中朝"身后"扔 3 级球 → 获得向前冲量越过缺口；
球落在对面墙上停下，可以踩着它回来或作为下一步的踏板。
```
**成本**：程序 ½ 天（`Throw` 里 `rb.AddForce(-dir * power * k)` + 放开空中限制 + 一条教学文本）。
**风险**：会破坏现有 6 关的平衡感，建议**只在新关使用**，不改老关。

### 方案 C：磁极碰撞（Polarity）——"同极相斥、异极相吸"

**机制**：磁性块分两种颜色（红/蓝）。球撞红块 → **被弹开且 +1 动量**（可链式加速）；撞蓝块 → **被吸住并停下**（变成可站立的平台）。场上所有磁块颜色由一个开关通道统一翻转。

**与现有实现的区别**：反射镜是"固定角度反弹"，黏块是"减速后粘住"。C 方案是**条件化的行为**——同一个方块，因为极性不同既能当加速器又能当落脚点，且可以用开关在关卡中途整体翻转。

**关卡草图**：一道 8 格高的竖井，中段是红磁块阵列。玩家把球打上去，球被反复弹射累积到 5 级动量，撞碎顶部的石头，落下的碎块压住压力板。翻转极性后同样的路变成"台阶"，玩家自己能爬上去。

**成本**：程序 1 天（新增 `TileType.MagnetPolar`，`OnSignal` 里改 `isAttract`，`BoxProjectile.OnBlocked` 加分支）。

> 变体 D（更便宜）：**精确共振**——把 `BallBreakThreshold` 的 `speedLevel >= required` 改成 `speedLevel == required`，多一级就反弹。让"蓄力"从"越大越好"变成"精确打击"，能直接把现有 6 关变成音游式节奏关。**½ 天成本**，但会改变全部关卡的解法，需谨慎。

**建议**：一周内最多做 **1 条**（选 A，成本最低、最贴关键词），其余写进 itch 页面的"未来计划"。

## 5. 剧情展开点（适配像素可爱风）

现有美术是**粉发猫耳小女孩**（`PlayerIdle.png`），而代码里的教学文案已经把球称作 **"猫猫"**（"按E键可以收回猫猫"、"按住左键瞄准发射猫猫"、"猫猫也爱走些斜路"）。**剧情其实已经埋在文案里了，只需要把它统一成一个完整的故事。**

### 方案 1：「猫猫回家」（推荐，成本最低）

**设定**：女孩的猫被"方块化"了——它就缩成了一枚黄色小球，也就是玩家手里的 `Ball`。猫撞在方块上会被弹回来，女孩要一路把它"撞"回家门口。

**为什么契合**：
- 现有文案已经在叫"猫猫"，**零改造成本**；
- 每个机关都能用"猫的习性"解释：猫讨厌黏的东西（Sticky）、猫喜欢钻进果冻（Jelly）、猫看到镜子会炸毛（Mirror）、猫在滑面上刹不住（Slider）；
- 美术只需要：猫球 3 档表情（困/一般/炸毛）+ 结尾一张"猫躺在女孩头上"的插画。

**叙事节奏**：每关开场一句独白（1 行，显示在关卡标题卡上）：
1. "第一天：它把自己压成了一个球。"
2. "它好像还挺喜欢这样。"
3. "但它开始往奇怪的方向弹了。"
4. ……
6. "到家了。喂，别装了，我知道你会变回来。"

### 方案 2：「撞出来的记忆」（推荐搭配方案 1）

**设定**：女孩记不清以前的事了。每撞碎 **N 个方块**（比如 15 个），场上会掉落一张像素明信片；6 张凑齐拼成一张全家福。

**为什么契合**：
- 把**"碰撞"这个关键词和叙事直接绑死**——不撞就没有故事；
- 每张明信片只是一张 240×160 的像素图，**6 张插画成本可控**；
- 给速通玩家一个"多撞几下"的理由，变相延长游玩时长。

**实现**：`BoxProjectile` 破块处计数（已有 `speedLevel -= 1` 的分支），满 N 就 `Instantiate` 一个 Pickup 变体；`PlayerPrefs` 记已收集。

### 方案 3（备选，0 文本）：「把世界弹回去」

**设定**：无任何文字。世界被"压扁"了，墙上的涂鸦是哭脸。每通关一次，玩家所在场景的装饰贴纸从 😢 变成 😊，最后一关结束时所有贴纸一起变笑脸。

**成本**：8 张表情贴图 + 每关几个 SpriteRenderer，**1 个美术半天**。适合"时间实在不够但想要情绪"的兜底方案。缺点是叙事弱，只有情绪没有故事。

**建议**：主叙事用 **方案 1**，收集系统用 **方案 2**（若时间不足，方案 2 可砍）。两个方案共用同一批素材：猫球表情 + 6 张明信片，美术总投入约 1.5 天。
